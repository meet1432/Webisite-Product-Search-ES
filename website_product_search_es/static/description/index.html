Website Product Search (Elasticsearch)

High-performance Odoo 16 eCommerce search with smart suggestions, dynamic indexing, advanced filtering, and product badges.

Odoo 16

Key Features

1. Lightning-Fast Website Search
Elasticsearch replaces slow database pattern matching for product discovery. Customers get faster response time, even on large catalogs.

2. Smart Search Dropdown UI
The module replaces the default shop autocomplete dropdown with a richer experience that shows product image, name, category, badges, and formatted price.

3. Real-Time Autocomplete Suggestions
While users type, live suggestions are returned from Elasticsearch. This helps customers discover products faster with fewer clicks.

4. Trending Searches + Trending Products
Search interactions are logged and used to show trending search terms. Trending product suggestions are also supported to improve product discovery.

5. Advanced Search Filters
Customers can refine results using category, brand, attributes, minimum price, and maximum price from the website search flow.

6. Dynamic ES Indexing Configuration
Admins can configure indexing for models with custom domains, mapped fields, searchable flags, and field-level search boosts for better relevance tuning.

7. Optional Auto-Sync on Data Changes
When auto-sync is enabled, Elasticsearch documents are updated on create/write/unlink events. When disabled, indexing is controlled via manual run or cron.

8. Product Badge Intelligence
Products are automatically tagged as Bestseller, Trending, or New Arrival using configurable business rules. Badges appear on shop cards, product pages, and backend kanban/list views.

9. Graceful Fallback Behavior
If Elasticsearch is temporarily unavailable, the module falls back to Odoo ORM search to keep the website functional.

Quick Setup

  • Go to Settings → Elasticsearch Search.
  • Set ES URL (example: http://localhost:9200) and index name.
  • Click Test Elasticsearch Connection.
  • Open Website → Configuration → Dynamic ES Indexing.
  • Create/adjust index config and run Index Now.
